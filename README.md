# Voices of the Future: companion code

Runnable notebooks and code for [*Voices of the Future*](https://books.sugiv.fyi/voice_applications/intro.html), a hands-on book about building with modern voice AI models.

Across the book you build one project: a voice receptionist for **Halfwheel Cycles**, a fictional bike repair shop. It answers calls, books repairs, checks whether a bike is ready, answers questions, takes messages and screens spam calls.

## Running the code

Every notebook runs on a **free Google Colab T4 GPU** or on your own laptop with an NVIDIA GPU. Where a good Apple Silicon (MLX) path exists, the chapter shows it too. Small demos run on CPU.

Each chapter folder has its own `requirements.txt` and an "Open in Colab" link.
